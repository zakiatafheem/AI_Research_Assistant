# 🤖 AI Research Assistant

An Agentic AI-powered research assistant built using **LangChain**, **Groq LLM**, **Tavily Search API**, and **Streamlit** that performs autonomous web research and generates structured insights on any topic.

---

# 🚀 Features

- Autonomous AI research workflow
- Real-time web search integration
- LLM-powered summarization
- Structured research reports
- Trend & insight extraction
- Streamlit interactive UI
- Agentic AI reasoning pipeline

---

# 🧠 Problem Statement

Traditional search engines provide raw links and scattered information, requiring users to manually analyze and summarize content.

This project solves that by creating an AI-powered research assistant capable of:
- understanding a research query
- searching the web autonomously
- extracting relevant insights
- summarizing findings
- generating structured research reports
